The Interview Process

The interviewer is looking for
	Analytical skills
		Edge cases
		Optimal solution
		Trade offs
	Coding skills
		Translate algorithm to code
		Good style
	Technical knowledge
		Strong fundamentals
	Experience
		Good decisions
		Built interesting, challenging projects
		Drive, initiative, and other important factors
	Culture fit/Commnication skills
		Company fit
		Communication with interviewer

People agree that
	Lots of great candidates fail
	Answers can be looked up if needed
	Rarely are many niche data structures used
	White board coding is an artificial environment

However
	False negatives are an acceptable trade off for companies versus false positives
	Problem-solving skills are valuable
	Basic data structures and algorithm knowledge is useful
Grading is relative
	Comparison to everyone who that interviewer has seen before
